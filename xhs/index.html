把一份 JSON 变成 8 张小红书图文，自动填好等你发布

整套流水线用 Python 标准库 + Edge 调试协议驱动，不需要 Playwright / Selenium，也不上传你的账号信息。 中文用代码排版，不会被 AI 画糊；发布默认停在最后一步，由你按发送。

去仓库下载 看代码

它帮你做四件事

1代码排版出图标题、正文、页码用 Pillow 画出来，画布 1080×1440（3:4）。字号边距固定，一整套看起来是同一套设计。
2自动填表上传图片 → 填标题 → 填正文 → 加标签 → 原创声明 → 内容声明，全在创作服务平台里完成。
3两种视觉风格手账风（hand）和深色海报风（poster），改一个字段就切换。
4选题与流水选题池 + 发布记录，自动跳过发过的；还能抓同行热门笔记找选题。

三步跑起来Windows + Edge

  1. 拿代码：把仓库的 xhs-auto/ 目录下载到本地任意位置。
  2. 登录一次：双击 start_edge.bat，在弹出的 Edge 窗口里扫码登录小红书。 这个窗口用的是独立配置目录，不影响你平时用的浏览器，登录态只存在你自己电脑上。
  3. 出图并上传： 
    pip install -r requirements.txt
copy content.example.json content.json   # 换成你自己的文案
python render_pages.py                   # 出图到 pages/
python auto_post.py                      # 全自动；加 --no-publish 就停在发布前

关于账号和数据

仓库里不含任何账号信息：登录态在你自己电脑的 edge-profile/ 里，已被忽略规则排除。
也不带现成文案和选题：content.json、topics.json、history.json 都由使用者自己填，仓库里只放模板。
脚本只操作你本机的 Edge，不把数据发往第三方服务器。
用自动化操作第三方平台可能违反其用户协议，账号风险自负；建议一天 1-2 篇、发布前人工过一眼。

常见问题

提示需要登录？ 在弹出的那个 Edge 窗口里扫码，然后重跑脚本。
找不到 Edge？ 设置环境变量 EDGE_PATH 指向 msedge.exe。
找不到标题/正文框？ 前端改版了，照 logs/ 里的截图改 publish.py 顶部的选择器。
能换 Chrome 吗？ 能，两者都是 Chromium，调试协议一样，把 EDGE_PATH 指过去即可。

# 聊天参谋（网页版）

一个帮你把话说好、给你找话题的小工具。网页读不到微信界面——是你主动把聊天内容
（粘贴文字或上传截图）交给它，它给出接话方向、话题和措辞。

**它辅助你聊，不替你聊。** 默认只给方向和抓手，不给成品句。

在线地址：https://lvyangg.github.io/lyy/

站点根目录就是本分支，完整说明见 `使用说明.md`。

发布方式：仓库 Settings → Pages → Source 选 **Deploy from a branch**，
分支选 `chat-helper`、目录选 `/ (root)`。推一次分支就自动重新发布，不需要工作流。
